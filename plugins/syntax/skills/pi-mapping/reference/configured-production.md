## Notes
- Lookup detection is by the function GUID actually wired into the mapping's graphical tree (a tf `brick`), not the `UsedFuncLib` link — the latter over-counts (libraries are declared but often not called).
- `%s` placeholders in a resource/filter are filled at runtime from the listed source fields.
- The OData host comes from the channel; the lookup base path is `/sap/opu/odata/sap/<service>`.
